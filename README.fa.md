# Motion Skill Scout — پیشنهادگر تعاملی اسکیل‌های موشن

**یک اسکیل ایجنت تعاملی که اول دربارهٔ ویدیوی مورد نظرت سؤال می‌پرسد، بعد یک «پشتهٔ» مناسب از اسکیل‌های ویدیو و موشن پیشنهاد می‌دهد، و فقط چیزی را نصب می‌کند که صریحاً تأیید کنی — پین‌شده روی یک کامیت مشخص.**

[English](README.md) · فارسی

بیشتر فهرست‌های «awesome video skills» جواب می‌دهند *چه چیزی وجود دارد*. این اسکیل جواب می‌دهد *برای این پروژه، با این فوتج، در این زبان و با این مجوز، چه چیزی باید نصب کنم* — و پیش از گرفتن تأیید، به فایل‌های تو دست نمی‌زند.

```text
تو     یک کلیپ گفتارمحور فارسی دارم. ظاهر پروندهٔ کاغذی می‌خواهم.
اسکیل چهار سؤال کوتاه، بعد:
       پایه      remotion-dev/skills        رسمی · رندر را فریم‌درست نگه می‌دارد
       اصلی      iart-ai/b-roll-skills      MIT · بی‌رول هم‌زمان با کلمه، صدای اصلی حفظ می‌شود
       اختیاری   louisedesadeleer/cut-video MIT · حذف سکوت و کلمات پرکننده
       هشدار: راهنمای RTL ندارد؛ شکل‌دهی فارسی را قبل از رندر کامل تست کن.
       این پشته نصب شود؟  [نصب] [تغییر گزینهٔ اصلی] [جایگزین‌ها] [توقف]
تو     نصب کن.
اسکیل کامیت‌ها را resolve می‌کند، نسخهٔ پین‌شده را در ‎.claude/skills/‎ می‌گذارد،
       فایل skills.lock.json را می‌سازد، همهٔ SKILL.md‌ها را بررسی می‌کند،
       ffmpeg و Node را چک می‌کند و یک پرامپت شروع تحویل می‌دهد.
```

هیچ چیز پیش از سؤال تأیید دانلود، کلون یا اجرا نمی‌شود.

## چرا لازم است

انتخاب اسکیل موشن مسئلهٔ جست‌وجو نیست؛ مسئلهٔ محدودیت است:

- **موتور** — Remotion، HyperFrames، After Effects، Manim، یا هنوز هیچ‌کدام.
- **فوتج** — گفتارمحور، تصویر محصول، یا فقط موشن.
- **زبان** — فارسی/عربی راست‌به‌چپ، تایپوگرافی، اتصال حروف و هندسهٔ زیرنویس را عوض می‌کند.
- **مجوز** — بستهٔ غیرتجاری برای کار مشتری گزینه نیست.
- **تجربه** — پروژهٔ اول به پایپ‌لاین نیاز دارد؛ حرفه‌ای به بستهٔ مهارتی.

اسکیل دو دور کوتاه سؤال می‌پرسد، یک کاتالوگ بررسی‌شده را به‌صورت قطعی امتیاز می‌دهد، و برای هر مورد در یک جمله دلیل و هشدار می‌گوید.

## نصب

با skills CLI:

```bash
npx skills add SaeedSheikhAmiri/motion-skill-scout
```

یا نصب دستی و پین‌شده:

```bash
SHA=$(git ls-remote https://github.com/SaeedSheikhAmiri/motion-skill-scout.git HEAD | cut -f1)
git init .claude/skills/motion-skill-scout
git -C .claude/skills/motion-skill-scout remote add origin https://github.com/SaeedSheikhAmiri/motion-skill-scout.git
git -C .claude/skills/motion-skill-scout fetch --depth 1 origin "$SHA"
git -C .claude/skills/motion-skill-scout checkout FETCH_HEAD
```

اگر ایجنت تو از `.codex/skills/`، `.cursor/skills/` یا `.agents/skills/` می‌خواند، همان مسیر را استفاده کن. پوشه باید همین `SKILL.md` را داشته باشد.

بعد به ایجنت بگو:

> می‌خواهم یک ویدیوی موشن بسازم. از motion-skill-scout استفاده کن.

## چطور کار می‌کند

| مرحله | چه اتفاقی می‌افتد | شبکه |
|---|---|---|
| ۰. پیش‌بررسی | Node، git، ffmpeg، ffprobe، npx و فضای دیسک | بدون شبکه |
| ۱. مصاحبه | دو دور، حداکثر چهار سؤال در هر دور | بدون شبکه |
| ۲. امتیازدهی | `scripts/recommend.mjs` کاتالوگ را رتبه می‌دهد | بدون شبکه |
| ۳. تصمیم | یک سؤال: نصب، تغییر، جایگزین‌ها، توقف | بدون شبکه |
| ۴. تأیید | کامیت‌ها و مقصد دقیق نمایش داده می‌شود | فقط `git ls-remote` |
| ۵. نصب | `vendor.sh` هر SHA را کلون می‌کند، بعد `lock.mjs` | کلون از GitHub |
| ۶. بازبینی | `scan-skills.mjs`، `verify-lock.mjs`، پیش‌بررسی | بدون شبکه |

پشته سه نقش دارد:

- **پایه** — موتور را درست نگه می‌دارد (قطعیت فریم، زیرنویس، مسیر رندر).
- **اصلی** — ظاهر و گردش‌کار کار تو را می‌سازد.
- **اختیاری** — پاک‌سازی‌ای که اصلی پوشش نمی‌دهد، مثل حذف سکوت.

سقف، سه نصب است. پنج بستهٔ جدید با پیش‌فرض‌های متناقض، همان چیزی است که پروژه را متوقف می‌کند.

## مدل امنیت

- `recommend.mjs` آفلاین و قطعی است. همان پاسخ‌ها و همان کاتالوگ، همان نتیجه.
- `vendor.sh` فقط **SHA کامل ۴۰ کاراکتری** می‌پذیرد. شاخه و تگ رد می‌شوند تا بعداً چیزی خودکار جلو نرود.
- `lock.mjs` مخزن، کامیت، مجوز، تعداد فایل و یک مانیفست SHA-256 از درخت نصب‌شده را در `skills.lock.json` ثبت می‌کند.
- `verify-lock.mjs` اگر فایلی تغییر کند، اضافه شود یا حذف شود خطا می‌دهد — شاهد اینکه اسکیل نصب‌شده بی‌صدا عوض نشده است.
- پیش از نصب، `SKILL.md`، اسکریپت‌ها و `LICENSE` مقصد را بخوان. این اسکیل آن خواندن را به‌جای تو انجام نمی‌دهد و اگر مجوز با استفادهٔ گفته‌شده نخواند، نصب نمی‌کند.

### آپدیت‌ها عامدانه دستی‌اند

این اسکیل خودش را آپدیت نمی‌کند، در پس‌زمینه به‌روزرسانی چک نمی‌کند، و هرگز `git pull`، `npm update` یا `npx skills update` را روی بسته‌های نصب‌شده اجرا نمی‌کند. آپدیت به درخواست تازه، تأیید تازه، بازبینی diff و ثبت lock تازه نیاز دارد. مجوز هم همین را با زبان حقوقی می‌گوید.

## کاتالوگ

`references/catalog.json` عکس لحظه‌ای **۴۱ مخزن** در **۱۴ نوامبر ۲۰۲۶** است: ستاره و مجوز از GitHub API، و وجود `SKILL.md` در درخت هر مخزن بررسی شده. شامل اسکیل‌های رسمی موتور، زیبایی‌شناسی کاغذ و کلاژ، موشن هم‌زمان با کلمه، پایپ‌لاین‌های کامل، ایجنت‌های تدوین، ابزارها و موتورها.

کاتالوگ گزیده است، نه کامل. برای حدود ۵۰۰ مخزن نمره‌گذاری‌شده از نظر امنیتی، [zhuyansen/awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills) را ببین.

ستاره و مجوز تغییر می‌کنند. پیش از همکاری پولی دوباره بررسی کن؛ تاریخ عکس لحظه‌ای در هر پیشنهاد چاپ می‌شود.

## پیش‌نیازها

- ایجنتی که `SKILL.md` را پشتیبانی کند (Claude Code، Codex، Cursor و دیگران).
- Node.js 18+ برای اسکریپت‌ها.
- `git` برای نصب پین‌شده.
- `ffmpeg`/`ffprobe` برای هر مرحلهٔ تدوین، مالتی‌پلکس و کنترل کیفیت.
- `npx` فقط اگر skills CLI را به وندور کردن ترجیح می‌دهی.

## ساختار مخزن

```text
SKILL.md                  قراردادی که ایجنت دنبال می‌کند
references/
  questionnaire.md        بانک سؤال دوزبانه و قواعد شاخه‌بندی
  scoring.md              اسکیمای پاسخ، وزن‌ها، نگهداری کاتالوگ
  catalog.json            عکس لحظه‌ای بررسی‌شده برای امتیازدهی
  install-safety.md       پیش از نصب چه چیزی را بخوانیم
  update-policy.md        روند آپدیت دستی و بازگشت
scripts/
  preflight.mjs           بررسی محیط
  recommend.mjs           رتبه‌بندی قطعی پشته
  vendor.sh               کلون پین‌شده با SHA
  scan-skills.mjs         یافتن و توصیف فایل‌های SKILL.md
  lock.mjs                نوشتن skills.lock.json
  verify-lock.mjs         تشخیص تغییر
examples/
  answers-persian-talking-head.json
  answers-english-html-explainer.json
LICENSE
```

## بدون نصب هم امتحان کن

```bash
node scripts/recommend.mjs --answers examples/answers-persian-talking-head.json
```

پشته و فهرست هشدارها را چاپ می‌کند و بدون دست‌زدن به شبکه خارج می‌شود.
